# Tone Calibration by Page Type

Not every page is a conversion landing page. Match tone to context.

| Page type | Tone | Pain framing | CTA intensity |
|-----------|------|-------------|---------------|
| Homepage, landing page | Confident + persuasive | Name the pain directly using VoC language | Strong, action-oriented |
| Pricing page | Transparent + reassuring | Address pricing fears, contrast with competitor patterns | Medium, clear next step |
| Feature page | Clear + specific | Light pain setup, focus on how it works | Medium |
| App Store listing | Factual + professional | Minimal — describe what the product does, not what others don't | Soft, "Install free" |
| About page, LinkedIn, company profiles | Warm + confident | None — describe who you are positively, not by attacking others | Soft or none |
| Case study | Story-driven + credible | Customer's own words about their before state | Soft |
| Partner page | Collaborative + respectful | None | Soft |

## Key Rule for Profile/About Pages

These are introductions, not sales pitches. Write like you're telling someone what you do at a dinner party — clear, proud, zero attack mode. Describe your own approach positively ("Core features on every plan") rather than framing competitors negatively ("other apps gate features behind expensive plans").
