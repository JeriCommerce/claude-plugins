# Communication Plugin

On-brand content creation for JeriCommerce across all channels. Supports English, Spanish, and Italian.

## Skills (auto-invoked)

| Skill | When it activates |
|-------|-------------------|
| **jericommerce-copywriting** | Writing or improving marketing copy for JeriCommerce pages |
| **jericommerce-cold-email** | Writing cold outreach emails to Shopify merchants |
| **jericommerce-social-content** | Creating social media posts (LinkedIn, Twitter/X, Instagram) |
| **jericommerce-voc-research** | Mining customer reviews/forums for voice-of-customer quotes |

## Commands

| Command | Description |
|---------|-------------|
| `/communication:write-copy <page-type> [lang]` | Write marketing copy (homepage, landing, pricing, feature, about, app-store, case-study) |
| `/communication:cold-email <target> [lang]` | Write cold emails targeting Shopify merchants |
| `/communication:social-post <platform> [lang]` | Create social posts (linkedin, twitter, instagram) |
| `/communication:voc-research <source-or-topic>` | Mine VoC quotes from a source or topic |

**Language options:** `en` (default), `es`, `it`

## Shared References

All skills share these embedded references:

- `references/brand-guide.md` - Complete brand guide: voice, tone, banned words, competitor rules, metrics, audience messaging
- `references/product-context.md` - Product details, ICP, positioning, proof points
- `references/voc-quote-bank.md` - 120+ real merchant quotes organized by pain theme

## Key Rules

1. **Loyalty first** - JeriCommerce is a loyalty platform, not a wallet tool
2. **Never name competitors** in published content
3. **Soft CTAs only** - no hard sell
4. **No banned words** - no em dashes, "seamless," "innovative," "leverage," etc.
5. **Customer language** - mirror how merchants talk, not marketing speak

## Prerequisites

No external tools required. All context is embedded in the plugin's references.
